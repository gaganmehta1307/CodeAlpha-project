# CodeAlpha-project — MehtaMart

Simple e-commerce demo site built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Features

- Product browse, search, and categories
- Product detail pages
- Shopping cart (saved in browser localStorage)
- Checkout and order confirmation
- Login and register (demo accounts stored in localStorage)
